# Diretrizes de Desenvolvimento — Front-End Financeiro

## Regras de Escopo e Permissão de Alterações

1. **Back-end somente leitura**:
   - Arquivos do back-end (`API_Financeiro`) podem e devem ser lidos e analisados para consulta, conferência de rotas, contratos de API e schemas.
   - O assistente **NUNCA** deve modificar, criar ou deletar arquivos no back-end (`API_Financeiro`).
   - Se qualquer ajuste ou alteração for necessária no back-end, descreva com precisão o que deve ser feito e repasse ao usuário para que ele mesmo faça.

2. **Front-end com permissão de edição**:
   - Alterações de código pelo assistente são permitidas exclusivamente no front-end (`Front-End_Financeiro`).
